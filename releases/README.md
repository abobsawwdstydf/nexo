# Нексо — Установочные файлы

Все версии мессенджера Нексо для разных платформ.

---

## Android (смартфоны и планшеты)

| Файл | Минимальная версия Android | Тип сборки | Размер |
|------|--------------------------|------------|--------|
| `android/Нексо-v1.0.0-android-5.0+-debug.apk` | Android 5.0 (Lollipop)+ | Debug | ~15 МБ |

**Установка:**
1. Скачать `.apk` файл на телефон
2. Открыть файл → "Установить из неизвестных источников" (если первый раз)
3. Установить

---

## iOS (iPhone, iPad)

| Файл | Минимальная версия iOS | Тип сборки | Размер |
|------|----------------------|------------|--------|
| `ios/Нексо-v1.0.0-ios-15.0+-unsigned.ipa` | iOS 15.0+ | Unsigned (без подписи Apple) | ~10 МБ |

**Установка:**
- Unsigned IPA требует джейлбрейк или AltStore/Sideloadly для установки на iPhone/iPad
- Без подписи Apple в App Store не установить напрямую

---

## Windows (ПК и ноутбуки)

| Файл | Архитектура | Тип установщика | Размер |
|------|-------------|-----------------|--------|
| `windows/Нексо-v1.0.0-windows-x64.msi` | x64 (Intel/AMD 64-bit) | MSI-установщик | ~3 МБ |

**Установка:**
1. Двойной клик по `.msi`
2. Следовать мастеру установки
3. Приложение появится в меню "Пуск"

---

## macOS (MacBook, iMac)

| Файл | Архитектура | Тип установщика | Размер |
|------|-------------|-----------------|--------|
| `macos/Нексо-v1.0.0-macos-arm64.dmg` | ARM64 (Apple Silicon M1/M2/M3/M4) | DMG-диск | ~4 МБ |

**Установка:**
1. Открыть `.dmg`
2. Перетащить приложение в папку "Программы"
3. При первом запуске: правый клик → "Открыть" (macOS запросит подтверждение)

---

## Linux (ПК и ноутбуки)

| Файл | Архитектура | Формат пакета | Размер |
|------|-------------|---------------|--------|
| `linux/Нексо-v1.0.0-linux-x86_64.deb` | x64 (Intel/AMD 64-bit) | DEB (Debian/Ubuntu) | ~4 МБ |

**Установка (Ubuntu/Debian):**
```bash
sudo dpkg -i Нексо-v1.0.0-linux-x86_64.deb
sudo apt-get install -f  # исправить зависимости если нужно
```

## Имя файла — расшифровка

```
Нексо-v{ВЕРСИЯ}-{ПЛАТФОРМА}-{МИНИМАЛЬНАЯ_ВЕРСИЯ}[-{ТИП_СБОРКИ}].{РАСШИРЕНИЕ}

Примеры:
  Нексо-v1.0.0-android-5.0+-debug.apk     — Android, от 5.0, debug-сборка
  Нексо-v1.0.0-ios-15.0+-unsigned.ipa      — iOS, от 15.0, без подписи Apple
  Нексо-v1.0.0-windows-x64.msi             — Windows x64
  Нексо-v1.0.0-macos-arm64.dmg             — macOS Apple Silicon
  Нексо-v1.0.0-linux-x86_64.deb            — Linux x64 (Debian/Ubuntu)
```
